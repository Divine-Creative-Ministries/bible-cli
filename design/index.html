Bible CLI · mobile UX

Design exploration for the iOS + Android app, based on docs/mobile-app-plan.md (v4). Mockups only: no real app code. Best viewed on a phone.

Clickable prototype →Direction “Rubric”. Start at onboarding, or jump to any screen below. Three visual directionsRubric (recommended) · Vigil · Clearwater

In the prototype, tap a red verse number to select a verse, and tap words in John 15:4–5 to open the Greek word sheet. On a phone, the ☰ button returns here.

Key flows

1 · Highlight a passage and send it to ChatGPT, Claude or Grok Bot

  1. Tap verse numbers 4 and 5. The tab bar turns into the action bar. sel
  2. Highlight, then pick a named color (“promise”). hl
  3. Send to… opens with the last target (Claude) preselected. The three agents get equal tiles in alphabetical order, then Other and Copy. send
  4. Optionally add a question and include your highlight or note; the preview shows exactly what’s shared.
  5. iOS: “Copy & open Claude” copies the text and opens the app; you paste. Android: “Send to Claude” hands the text straight to the app. Toggle iOS/Android in the sheet.
  6. Every send also lands in your inbox, so “check what I sent” works in any connected agent, Grok Bot included.

2 · An agent saves research, and it appears in the Journal

  1. In Claude: “save this to my Bible CLI research” → save_research → status: saved.
  2. Sync arrives with a push: “Claude saved research…”. Tap it to open the item. push
  3. Journal → Research shows it on top: New · Saved by Claude, in slate-blue agent ink. research
  4. The reader marks it in place: a “1 research” chip on John 15 and a ◆ at v.4. read
  5. The detail view shows OBSERVED / PATTERN / INFERENCE labels, the tools used, a link back to the conversation, and Undo. detail

3 · Approve or undo agent saves

  1. Agents tab: a badge counts pending items, and the “From your agents” feed lists today’s saves with Undo. agents
  2. Needs approval: one card per item, with its reason (approval mode or over daily limit #101). Reject · Edit · Approve; Approve all. approvals
  3. Undo lives in three places: the feed row, the item itself, and “Undo everything Claude saved today” on the agent page. Restorable for 30 days.
  4. To tighten up, switch the agent to Approval required or Read only on its page. It applies on the agent’s next call. agent

4 · Connect a new agent

  1. Agents → + → pick ChatGPT, Claude or Grok Bot. If consent was “Not now”, the consent screen comes first. add
  2. Claude / ChatGPT: find Bible CLI in the directory → Connect → the Bible CLI sign-in page shows mode (Full access), data access and limit → Allow or Customize. oauth
  3. Back in the app, Test connection checks Scripture tools, reads and saves (it catches plans that block writes). A first-connect push follows: “Claude is connected with Full access. Change?”
  4. Grok Bot (custom connector): Create token → name, mode, expiry (Never by default) → token → token shown once, with Name / URL / Header copy rows → created → test.

5 · Start reading with tap-a-word

  1. Onboarding offers the Greek & Hebrew pack, on by default. pack It downloads behind the consent and sign-in steps (progress pill). consent
  2. First visit to Read: a one-line coach mark. read
  3. Tap “Remain”: the phrase is underlined in red, the verse scrolls above a half-height word sheet (μείνατε, parsing in plain English, BSB renderings, distribution, lexicon). word
  4. Tap “will remain” to see Added for English sense: the Greek has no verb there. supplied
  5. Toggle αβ for the interlinear (Greek order, tap a block ↔ English phrase). interlinear Hebrew runs right to left. hebrew
  6. If the pack was skipped, the first tap shows a one-sheet download prompt. prompt
