Type
Literata for Scripture (built for long reading, covers Greek) · Inter for UI · IBM Plex Mono for refs, Strong’s, tokens, logs · Ezra SIL / Noto Serif Hebrew
Color
Red only for structure (chapter numerals, verse numbers, the primary action). Slate blue means an agent made it. User highlights stay soft and named.
Density
Airy reader, medium-density lists. Detail (parsing codes, Strong’s) shows on demand.
Why
  • Feels like a Bible first, so it isn’t a dev tool with verses in it
  • Two inks give provenance a visual language: red is the text and its structure, blue is your agents
  • Has a natural dark mode (“Night” borrows Vigil’s palette)
Risk
  • Warm paper can look dated if the type isn’t crisp. Keep UI chrome minimal and modern.
